# ctOS - Голосовой мост (Voice Bridge)

Приложение на Electron для соединения нескольких собеседников в анонимном аудиочате с полным пультом мониторинга и маршрутизации звука.

---

## 🚀 Как запустить приложение

1. Откройте терминал в папке проекта:
   ```powershell
   cd d:\ctOS
   npm start
   ```
2. Откроется главное окно ctOS с карточками собеседников и пультом управления.

---

## 🎧 Как работает маршрутизация звука (Инструкция)

Чтобы вы могли **слышать собеседников**, **передавать голос одного другому** и **вклиниваться в разговор**:

### Встроенный Web Audio мост:
- Собеседники соединены напрямую через центральную виртуальную аудиоматрицу ctOS.
- **Удерживайте `Пробел` (SPACE)** или нажимайте кнопку **«Сказать всем»**, чтобы ваш собственный микрофон включился для всех окон.
- Кнопки **«Сказать ему»** включают трансляцию микрофона для конкретного окна или группы окон.
- Кнопки **«Следующий»** и **«Стоп»** автоматически отправляют команды управления поиском собеседника в каждом слоте.

---

## 🛡️ Защита от блокировок (Anti-Detect)
- Каждое окно запущено в строго изолированном профиле сессии (`persist:nekto_slot_1`, `persist:nekto_slot_2`...) — у них независимые Cookies, LocalStorage, IndexedDB и сессии WebRTC.
- Внедрен анти-детект скрипт скрытия следов автоматизации браузера (`navigator.webdriver = undefined`, подмена отпечатков Canvas/WebGL/Hardware).
