# ⚡ ctOS — Tactical Voice Bridge & Audio Matrix

**ctOS** — профессиональный софт и аудиоматрица для голосовых чат-рулеток (ChatFish и др.).
Позволяет соединять собеседников напрямую, управлять маршрутизацией звука, проигрывать звуки через Soundpad, циклически сохранять речь и записывать экран.

---

## ✨ Основные возможности

- 🎧 **Виртуальная аудиоматрица:** 
  - Трансляция голоса одного собеседника другому напрямую в реальном времени без задержек.
  - Режим **«Сказать всем»** (удержание `Пробел` или кнопка) — трансляция вашего микрофона сразу во все окна.
  - Режим **«Сказать ему»** — выборочная отправка вашего голоса в конкретные окна.
- 🎛️ **Встроенный Soundpad:**
  - Воспроизведение звуков и пранков в эфир собеседникам.
  - Поддержка горячих клавиш и поиска по трекам.
- 🎙️ **Циклический рекордер (Voice Catch):**
  - Запись последних 30 секунд разговора с возможностью обрезки в DAW-редакторе и мгновенного воспроизведения обратно в эфир.
- 📹 **Видеозахват экрана:**
  - Быстрая запись фрагментов для контента с предпросмотром и сохранением.
- 🛡️ **Полная изоляция сессий (Anti-Detect):**
  - Каждое окно функционирует в абсолютно изолированном контейнере с уникальными браузерными отпечатками (User-Agent, Canvas, WebGL, WebRTC).
  - Индивидуальная настройка прокси для каждого слота.
- 🔄 **Автоматические обновления:**
  - Приложение автоматически проверяет наличие новых версий на GitHub и обновляется в 1 клик.

## 📥 Скачивание и установка

1. Скачайте актуальный релиз **`ctOS 1.0.0.exe`** в разделе [Releases](https://github.com/slaymuffin/ctos-client/releases/latest).
2. Запустите приложение.
3. Активируйте доступ через официального Telegram-бота.
